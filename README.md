## 公式渲染

- 使用 KaTeX 代替 MathJax，提升首屏和展开时的公式渲染速度
- 题库采用按展开区块懒渲染，不处理隐藏内容
- 搜索输入增加防抖，避免每次按键都重建公式
- 自动修正历史数据中的双重 LaTeX 转义，并保持矩阵换行正确
- 所有题目均补齐独立的“正确答案”摘要，完整解答仍保留在分步解析中
- KaTeX 本地托管在 `shared/vendor/katex-0.16.11/`，不再依赖 jsdelivr（国内首次加载实测约 1.9 秒）

## 加载速度

- 题目与知识点的正文默认折叠，首次展开时才生成，不再一次性解析全部解答
- 搜索时按条目缓存检索文本，输入时不再重复序列化全部数据
- Netlify 构建时运行 `scripts/stamp-assets.mjs`：给页面引用的本地 JS/CSS 加内容指纹（`?v=哈希`）并生成 `_headers`，
  这些文件可被浏览器长期缓存；文件内容一变指纹就变，访客会立即拿到新版本。仓库源文件与本地 `npm start` 不受影响
- 可用 `node scripts/stamp-assets.mjs --dry-run` 检查，不会写入文件

## 组卷

两套题库的题目页左下角有「组卷」按钮，点开是组卷面板：

- 手动组卷：在每道题右侧点「＋ 组卷」加入试卷，再点一次移除
- 按条件抽题：按章节、题型、难度范围随机抽取指定题数，已在试卷中的题不会重复抽到
- 错题组卷：题库里记录的错题（编号以“错-”开头或带有当时答案/错因）自动算作错题；
  也可以在任意题目上点「标错」加入自己的错题本，抽题时选择「只抽错题」或一键「全部错题加入」
- 可设置标题、考试时间、说明和每题分值，默认按题型（选择、填空、判断、计算、证明、综合）分组并自动算满分
- 「预览 / 打印试卷」与「打印答案与解析」分开输出，A4 排版，可直接打印或在打印对话框中另存为 PDF
- 试卷篮与错题标记只保存在访客自己的浏览器里，不上传服务器

## 小节批注

- 每个小节标题旁提供默认折叠的“批注”入口
- 支持昵称、最多 300 字批注、最多 200 字回复、点赞和取消点赞
- 一级留言可按“最新”或“最热”排序；热度综合点赞与回复计算
- 线上数据保存在 Netlify Blobs；本地开发保存在各题库目录的 `.comments/`
- 用户可以随时撤回自己的批注或回复；列表每页加载 20 条留言，并按小节单独读取
- 批注与计数会在当前标签页缓存，悬停或键盘聚焦“批注”入口时提前预取
- 撤回和点赞先在界面即时生效，再与服务器同步；重复打开同一小节可直接显示缓存内容

## 目录结构

```text
/
├─ index.html             题库选择目录
├─ landing.css            目录页样式
├─ calculus/              微积分子站
│  ├─ index.html
│  ├─ admin.html
│  ├─ data.js
│  └─ ...
├─ linear-algebra/        线性代数子站
│  ├─ index.html
│  ├─ admin.html
│  ├─ data.js
│  └─ ...
├─ shared/                两套题库共用：公式渲染、批注、组卷（paper.js / paper.css）
│  └─ vendor/             本地托管的第三方库（KaTeX）
├─ scripts/               构建脚本（资源指纹与缓存头）
└─ server.js              本地预览与双题库发布服务
```

Netlify 部署 `main` 分支根目录；推送到 GitHub 后会自动更新线上站点。
