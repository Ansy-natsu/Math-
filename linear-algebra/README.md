# 线性代数内容管理后台

基于黄正达《线性代数（第二版）》九章内容建立的后台与公开预览站。

## 启动

```powershell
npm start
```

- 管理后台：<http://127.0.0.1:8788/admin.html>
- 公开预览：<http://127.0.0.1:8788/>

## 内容规模

- 9 个章节
- 91 道题目
- 22 个知识点
- 14 条易错点

## 功能

- 题目、知识点、易错点的增删改查
- 按章节、分类、题型、难度和关键词筛选
- 九章结构批量重命名
- 本地草稿、JSON 导入导出、`data.js` 发布
- 发布前自动在 `.backups/` 保存数据备份

后台视觉与交互沿用 `https://ansy.netlify.app/admin` 的内容管理布局，并针对线性代数内容替换了品牌、文案、章节与示例数据。
